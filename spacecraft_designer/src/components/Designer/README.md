# Designer Components

This directory contains the main React components for the SpaceCraft Designer app.

- **MainContainer.js**: The main application layout, housing the central canvas, sidebars, top action bar, and theming.
- **CanvasArea.js**: Central area for the design canvas, rendering elements and overlays.
- **MeasurementTools.js**: SVG overlay for interactive distance and area measurement on the canvas. Toggles via UI, modular and extensible.
- Future subcomponents (CanvasArea.js, LeftSidebar.js, TopBar.js, RightSidebar.js, etc.) should be added here for modularity.
